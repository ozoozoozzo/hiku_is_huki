# Hiku Is Huki Public Site

This repository contains the generated static website for Hiku Is Huki, a portfolio of artworks and writing by Kuang, Zhou.

The public repository is deployment-only. Editable source code, build scripts, development notes, and planning files are kept in the private source repository.

GitHub Pages serves this repository from the `main` branch.
